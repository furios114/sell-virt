## 📖 О проекте

Одностраничное SPA для магазина Telegram аккаунтов. Каталог с 240 странами, фильтрами по стране и отлеге, сортировкой по цене. Кнопка «Купить» открывает Telegram с готовым сообщением продавцу.

Дизайн — **премиум**: тёмная тема, золотой акцент, медленно летящие звёзды на фоне, плавные анимации появления.

## ✨ Возможности

- 🌍 **Каталог из 240 стран** — с флагами и кодами
- 🔎 **Живой поиск** — по названию страны или коду
- 🎛 **Фильтры** — страна и отлега (2013–2026)
- ↕️ **Сортировка** — по цене (дешёвые / дорогие)
- 💬 **Интеграция с Telegram** — «Купить» открывает чат с готовым сообщением
- 🎨 **Премиум-дизайн** — чёрный + золото, serif-заголовки
- ✨ **Анимированный фон** — canvas со звёздами
- 📱 **Полный адаптив** — от телефона до десктопа
- ⚡ **Ноль зависимостей** — чистый HTML, CSS, JS

## 🧩 Структура

| Секция | Описание |
|--------|----------|
| **Главная** | Hero, статистика, 4 шага покупки |
| **Каталог** | Фильтры, поиск, сортировка, карточки аккаунтов |
| **FAQ** | Аккордеон с частыми вопросами |
| **Контакты** | Карточка менеджера с кнопкой Telegram |

## 🛠 Стек

- **HTML5** — семантичная разметка
- **CSS3** — Grid, Flexbox, анимации, кастомные свойства
- **JavaScript (Vanilla)** — hash-роутинг, динамический рендер каталога
- **Canvas API** — фон со звёздами
- **GitHub Pages** — хостинг

## 🚀 Запуск

Проект не требует сборки и зависимостей.

```bash
git clone https://github.com/furios114/sell-virt.git
cd sell-virt

# Открыть в браузере
open index.html

Или запустить локальный сервер:
python -m http.server 8000

Затем открыть http://localhost:8000.
